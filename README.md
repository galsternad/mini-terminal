### Terminal in JS

Implementing a simple terminal-like interface in JS. Currently supports the following operations (operations marked with an '[x]' are currently supported by the parser):
- ```mkdir```,
- ```rmdir```,
- ```touch```,
- ```rm```,
- ```ls``` [x],
- ```pwd``` [x],
- ```write```,
- ```cat``` [x],
- ```wc```, [x]
- ```tree``` [x],
- ```find``` [x].
